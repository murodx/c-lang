# Изучение языка программирования C

Этот репозиторий создан для изучения языка программирования C.
## Содержание

### Основные главы
1. **Введение в С**
2. **Основы языка Си**
3. **Указатели**
4. **Функции**
5. **Препроцессор**
6. **Структуры**
7. **Динамическая память**
8. **Ввод-вывод и работа с файлами**
9. **Стандартная библиотека С**
10. **Многопоточность**
11. **Среды разработки для С**
12. **Взаимодействие с кодом Python**
13. **Дополнительные статьи**

### Дополнительные главы
1. **Управление ресурсами и обработка ошибок**
2. **Управление памятью**
3. **Возвращение результата из функции**
4. **Модули, API и управление состоянием**
5. **Перебор данных**
6. **Директива #ifdef и управление вариантами компиляции**
7. **Преобразование типов**

## О проекте

Я изучал все указанные выше темы и вёл данный проект, чтобы систематизировать и углубить свои знания в языке программирования C. \
Этот репозиторий представляет собой результат моего изучения, включающий примеры, пояснения и практические задания для освоения различных аспектов C.
